الدرس الخامس: بروتوكول DHCP

كيف يحصل جهازك على عنوان IP تلقائيًا؟ تعلّم دورة DORA والمنافذ والتجديد، مع رسوم وتمارين واختبار تفاعلي.

المدة: 70–100 دقيقة10 أقسام20 سؤالًا

1. ما هو DHCP؟

DHCP اختصار Dynamic Host Configuration Protocol، وهو بروتوكول يمنح الأجهزة إعدادات الشبكة تلقائيًا بدل إدخالها يدويًا.

📱 جهاز جديد
يطلب إعدادات الشبكة
← DHCP →
🖧 خادم DHCP
يعرض IP وإعدادات

مثال: عند اتصال هاتفك بالواي فاي يحصل عادة على عنوان IP والبوابة وDNS تلقائيًا.

DHCP لا ينقل صفحات الويب، ولا يحوّل أسماء المواقع إلى IP؛ هذه وظائف بروتوكولات وخدمات أخرى.

2. ما الإعدادات التي يوزعها؟

الإعدادمثالالوظيفة
IP Address192.168.1.105عنوان الجهاز داخل الشبكة
Subnet Mask255.255.255.0تحديد نطاق الشبكة المحلية

هذه أمثلة فقط؛ القيم الفعلية تختلف من شبكة إلى أخرى.

3. مراحل DORA الأربع

عندما يبدأ جهاز جديد بطلب إعدادات الشبكة، يحدث غالبًا التسلسل التالي:

1 — Discoverالجهاز يبحث عن خادم DHCP، غالبًا ببث رسالة على الشبكة المحلية.
2 — Offerالخادم يعرض عنوانًا وإعدادات متاحة.
3 — Requestالجهاز يطلب استخدام العرض الذي اختاره.
4 — Acknowledge (ACK)الخادم يؤكد منح الإعدادات ومدة الاستئجار.
ClientDiscover →Server
Client← OfferServer
ClientRequest →Server
Client← ACKServer

احفظها: Discover → Offer → Request → ACK. في بعض الحالات يمكن أن تختلف الرسائل، مثل تجديد الاستئجار أو رفض الإعدادات (NAK).

4. المنافذ وطريقة النقل

يستخدم DHCP في IPv4 بروتوكول UDP، عادةً المنفذ 67 للخادم و68 للعميل.

الطرفUDP Port
DHCP Server67
DHCP Client68

قد يبدأ العميل دون عنوان IP صالح، لذا قد يستخدم البث (Broadcast) للعثور على الخادم. أما DHCPv6 فيستخدم منفذين مختلفين: 546 للعميل و547 للخادم، وله آلية رسائل مختلفة عن DORA الخاص بـ DHCPv4.

5. مدة الاستئجار والتجديد

العنوان الموزّع عبر DHCP غالبًا مؤقت ويُسمّى Lease. يحاول الجهاز تجديده قبل انتهاء مدته. في إعدادات DHCPv4 الشائعة يبدأ التجديد عند T1 (نحو 50% من مدة الاستئجار) ثم إعادة الارتباط عند T2 (نحو 87.5%)، ما لم تُضبط قيم أخرى.

استلام IPT1: تجديدT2: إعادة ارتباطانتهاء المدة

إذا فشل التجديد وانتهت المدة، لا يجوز افتراض استمرار صلاحية العنوان. ويمكن حجز عنوان لجهاز معين بناءً على معرّف العميل أو MAC وفق إعداد الخادم.

6. DHCP مقابل DNS وStatic IP

المفهومماذا يفعل؟
DHCPيوزع إعدادات الشبكة تلقائيًا
DNSيترجم أسماء النطاقات إلى سجلات مثل عناوين IP
Static IPعنوان يضبط يدويًا أو يبقى ثابتًا حسب السياسة
DHCP Reservationخادم DHCP يمنح جهازًا محددًا عنوانًا محجوزًا
قد يعمل DNS وDHCP معًا: DHCP يخبر جهازك بعنوان خادم DNS الذي سيستخدمه.

7. تطبيق عملي آمن على جهازك

هذه أوامر للعرض والفحص فقط، لا تغيّر إعدادات الشبكة.

Windows

ipconfig /all

افتح Command Prompt وابحث عن DHCP Enabled وDHCP Server وLease Obtained / Expires.

Linux

ip address show
nmcli device show

قد لا يتوفر nmcli على كل توزيعات Linux. ابحث عن عنوان IPv4 وإعدادات DNS، ويمكن مراجعة معلومات الاستئجار عبر مدير الشبكة المستخدم.

تمرين

  1. اعرض إعدادات شبكتك بالأمر المناسب.
  2. حدد عنوان IPv4 والبوابة الافتراضية.
  3. تحقق هل DHCP مفعّل وما عنوان الخادم إن ظهر.
  4. قارن بين عنوان IP المحلي وعنوان DNS.

لا تشارك لقطات شاشة تحتوي على عناوين عامة أو معلومات شبكة حساسة دون إخفائها.

8. مخاطر DHCP والحماية

Rogue DHCP Server: خادم غير مصرح به قد يرسل إعدادات خاطئة للأجهزة.

DHCP Spoofing: مهاجم ينتحل دور خادم DHCP لإعطاء بوابة أو DNS خبيث، مما قد يوجّه المرور عبره.

DHCP Starvation: استنزاف مجموعة العناوين بطلبات كثيرة، ما قد يمنع أجهزة شرعية من الحصول على عنوان.

دفاعات شائعة: DHCP Snooping على المحولات المدعومة، تحديد المنافذ الموثوقة، مراقبة الخوادم غير المصرح بها، وتقسيم الشبكة. يجب ضبط هذه الحمايات وفق بنية الشبكة.
