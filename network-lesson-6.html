الدرس السادس: نموذجا OSI وTCP/IP

افهم كيف تنتقل البيانات بين التطبيقات والأجهزة، وكيف تساعدنا الطبقات على تشخيص مشكلات الشبكة وفهم الهجمات.

المدة: 70–100 دقيقة10 أقسام10 أسئلة

1. لماذا نقسم الشبكات إلى طبقات؟

تعمل الشبكات عبر مهام مختلفة: تطبيق يطلب صفحة، وبروتوكول نقل ينظم الاتصال، وعناوين تحدد وجهة الحزم، ووسيط فعلي يحمل الإشارات. تقسيم هذه المهام إلى طبقات (Layers) يجعل التصميم والفهم واستكشاف الأعطال أسهل.

نموذج OSI مرجع تعليمي من سبع طبقات، أما TCP/IP فهو مجموعة بروتوكولات عملية يُشرح غالبًا بأربع طبقات. لا يعني ذلك أن كل بروتوكول يطابق طبقة واحدة بصورة صارمة.

4. التغليف Encapsulation

عند إرسال البيانات، تضيف الطبقات معلومات تحكم إلى المحتوى، مثل منافذ النقل وعناوين IP ومعلومات إطار Ethernet. يسمى ذلك التغليف، ويُزال تدريجيًا عند الاستقبال (Decapsulation).

Application Dataبيانات التطبيق مثل طلب HTTP.
TCP Segment / UDP Datagramتُضاف معلومات النقل مثل المنافذ.
IP Packetتُضاف عناوين IP للمصدر والوجهة.
Link Frameتُضاف معلومات الوصلة المحلية لإرسال الإطار.
التسميات تختلف بحسب البروتوكول؛ ليست كل حركة مرور TCP، وليست كل الوصلات Ethernet.

5. الفرق بين MAC وIP وPort

العنصرماذا يحدد؟مثال
MAC Addressمعرّف واجهة على الوصلة المحلية (في شبكات مثل Ethernet)00:1A:2B:3C:4D:5E
IP Addressعنوان منطقي يُستخدم في التوجيه بين الشبكات192.168.1.20
Portخدمة أو عملية على الجهاز في TCP/UDP443

مثال: قد يتجه طلب متصفح إلى عنوان IP لخادم عبر منفذ 443، بينما يُرسل الإطار في كل وصلة محلية إلى عنوان MAC مناسب لتلك الوصلة.

6. مثال عملي: فتح موقع HTTPS

  1. تكتب عنوان الموقع في المتصفح، وقد يحتاج المتصفح إلى DNS للحصول على عنوان IP.
  2. ينشئ المتصفح اتصالًا مناسبًا؛ قد يكون TCP + TLS أو QUIC فوق UDP بحسب إصدار HTTP المستخدم.
  3. تُرسل حزم IP نحو الوجهة عبر الموجّهات (Routers).
  4. تُحمل الحزم داخل إطارات الوصلة المحلية مثل Wi-Fi أو Ethernet.
  5. يفك الطرف المستقبِل التغليف ويمرر البيانات إلى التطبيق.
مهم: HTTPS لا يعني دائمًا TCP؛ فـ HTTP/3 يستخدم QUIC فوق UDP.

التصنيف يساعد في تنظيم التشخيص، لكنه ليس بديلًا عن الأدلة؛ قد تتداخل أسباب العطل عبر أكثر من طبقة.

8. تطبيق عملي آمن

الأوامر التالية للفحص فقط، ولا تغيّر إعدادات الشبكة. اختر ما يناسب نظامك.

Windows

ipconfig /all
tracert example.com

Linux

ip address show
ip route

ماذا تستنتج؟

  1. حدد عنوان IP الخاص بواجهة الشبكة.
  2. حدد البوابة الافتراضية إن وجدت.
  3. قارن بين مفهوم عنوان IP ومفهوم المنفذ.
  4. على Windows، لاحظ أن tracert قد يعرض موجّهات على الطريق، لكن عدم ظهور بعض القفزات لا يعني بالضرورة وجود عطل.

9. لماذا تهم الطبقات في الأمن السيبراني؟

Link Layerمراقبة الشبكة المحلية وحماية المحولات من بعض الهجمات.
Network Layerقواعد التوجيه والتحكم في المرور حسب عناوين IP.
Transport Layerالتحكم في المنافذ واتصالات TCP/UDP.
Application Layerفحص طلبات الويب، والمصادقة، ومشكلات التطبيقات.

تساعد الطبقات محلل مركز العمليات الأمنية (SOC) على ربط مؤشرات مثل عنوان IP والمنفذ واسم النطاق ونوع البروتوكول لتكوين صورة أوضح عن الحدث.
